# Drops Tracker

MV3 extension that checks whether Twitch Drops minutes are really rising. Read-only: it never claims a drop or simulates watching, and must stay that way.

Overview and layout: [README.md](README.md). Commands and the rules that are easy to break: [CONTRIBUTING.md](CONTRIBUTING.md). Run `npm run check`, `npm test` and `npm run e2e` before calling a change done. Measured Twitch behaviour, by symptom: [docs/twitch-drops-facts.md](docs/twitch-drops-facts.md).
